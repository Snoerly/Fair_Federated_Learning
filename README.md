# Fair Federated Learning

This repository contains the code used to benchmark three fairness aware FL algorithms, and FedAvg as a baseline.
We report our findings in this [Paper]().

## Sources

### Algorithms

- [GIFAIR-FL](https://doi.org/10.1287/ijds.2022.0022)
- [FairTrade](https://doi.org/10.1609/aaai.v38i10.28971)
- [EnforcingGroupFairness](https://doi.org/10.1016/j.future.2024.06.040)
